# Third-party assets

The MIT license in `LICENSE` covers the source code of this project. It does
**not** cover the bundled sound effects, which are third-party work under their
own terms.

## Sound effects

**JDSherbert — Tabletop Games SFX Pack**

The files in `client/public/sfx/` are renamed ogg/mp3 copies from this pack.
The full source pack (`Assets/`, all formats) is not tracked in this repository.

Attribution is required by the pack's terms. Confirm the current license at the
pack's official listing before redistributing this repository's audio, and keep
this notice with any copy that ships the files.
